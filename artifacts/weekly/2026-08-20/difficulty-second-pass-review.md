# 難易度監査 第2回修正

## ENG-000023

- 旧問題 → 新問題: `She is about ___ close the window.` → `She is ___ to close the window.`
- 旧choices → 新choices: `['to', 'for', 'at', 'on']` → `['about', 'almost']`
- 旧learning point → 新learning point: `be about to＋動詞` → `be about to＋動詞`
- 正解: `about`

## ENG-000032

- 旧問題 → 新問題: `He is going ___ the stairs.` → `He is walking ___ the stairs.`
- 旧choices → 新choices: `['up', 'on', 'to', 'at']` → `['up', 'up to']`
- 旧learning point → 新learning point: `go up＝上る` → `upとup toの使い分け`
- 正解: `up`

## ENG-000034

- 旧問題 → 新問題: `She says he ___ sit there.` → `What does she say to him?`
- 旧choices → 新choices: `['can', 'cans', 'can to', 'is can']` → `['You can sit here.', 'I can sit here.']`
- 旧learning point → 新learning point: `can＋動詞` → `会話でのyouとIの使い分け`
- 正解: `You can sit here.`

## ENG-000046

- 旧問題 → 新問題: `The seat is free, so I ___ sit there.` → `Is anyone ___ here?`
- 旧choices → 新choices: `['can', 'can to', 'am can', 'cans']` → `['sitting', 'sit']`
- 旧learning point → 新learning point: `can＋動詞` → `現在進行形の疑問文`
- 正解: `sitting`
